# 공문서 자동 생성기

행정기관 표준 공문 서식(수신 · 경유 · 제목 · 본문 · 붙임 · 발신명의 · 시행문 정보)에 맞춰
Word(.docx) 문서를 자동으로 만들어주는 도구예요. 서버나 설치 없이 브라우저에서 바로 써요.

## 사용법

1. `official-docs/index.html` 파일을 더블클릭해서 브라우저로 열어요.
2. 두 가지 방식 중 하나를 골라요.
   - **✍️ 폼으로 한 건 만들기**: 왼쪽에 항목을 입력하면 오른쪽에 실제 공문서처럼 실시간 미리보기가 뜨고, "워드 파일 다운로드"를 누르면 `.docx` 파일이 저장돼요.
   - **📊 엑셀로 대량 생성**: "엑셀 양식 다운로드"로 빈 양식을 받아서 여러 건을 한 번에 채운 뒤 업로드하면, 각 행이 공문서 한 건씩 되어 `.docx` 파일들이 ZIP으로 한 번에 다운로드돼요.

모든 처리(문서 생성, 엑셀 읽기)는 브라우저 안에서만 이뤄지고, 입력한 내용이 어디로도 전송되지 않아요.
인터넷 연결 없이도(오프라인) 그대로 동작해요 — 필요한 라이브러리를 `vendor/` 폴더에 미리 담아뒀어요.

## 입력 항목

| 항목 | 설명 |
| --- | --- |
| 기관명 | 문서 상단에 표시되는 발신 기관명 |
| 수신 | 문서를 받는 대상 |
| 경유 | 경유 기관 (없으면 비워두기) |
| 제목 | 공문 제목 |
| 본문 | 줄바꿈으로 문단 구분, 필요하면 "1.", "가." 등 번호는 직접 입력 |
| 붙임 | 첨부 목록 (없으면 비워두기) |
| 발신명의 | 문서 하단에 표시되는 발신 명의(예: OO구청장) |
| 문서번호 / 시행일자 | 시행문 정보 |
| 우편번호 / 주소 / 전화번호 / 팩스번호 / 이메일 | 기관 연락처 정보 |
| 공개구분 | 공개 / 부분공개 / 비공개 |

문서 끝에는 규정에 따라 "끝." 표시가 본문(또는 붙임)의 마지막 줄에 자동으로 붙어요.

## 엑셀 대량 생성 사용 팁

- 엑셀의 열 이름은 위 입력 항목과 정확히 같아야 해요 ("엑셀 양식 다운로드"로 받은 파일을 그대로 쓰면 자동으로 맞아요).
- 본문/붙임 칸에서 여러 줄을 넣고 싶으면 셀 안에서 `Alt + Enter`로 줄바꿈해요.
- 제목과 본문이 모두 비어있는 행은 건너뛰어요.
- 파일명이 겹치면 자동으로 `_2`, `_3` 등을 붙여요.

## 참고

- 실무에서 쓰는 정식 결재란(기안자·검토자·결재권자 서명)은 포함돼 있지 않아요. 실제 기관 명의로 발송하기 전에는 소속 기관의 공문서 규정 및 결재 절차를 꼭 확인해주세요.
- `vendor/` 폴더에는 문서 생성을 위해 쓰는 오픈소스 라이브러리가 들어있어요: [docx](https://github.com/dolanmiu/docx)(Word 파일 생성), [SheetJS/xlsx](https://github.com/SheetJS/sheetjs)(엑셀 읽기/쓰기), [JSZip](https://github.com/Stuk/jszip)(여러 파일 압축).
