📄 공문서 자동 생성기

행정기관 표준 공문 서식(수신 · 제목 · 본문 · 붙임 · 발신명의)에 맞춰 Word(.docx) 문서를 만들어요. 서버 없이 이 브라우저 안에서만 처리돼요.

왼쪽에 내용을 입력하면
여기에 실시간으로 미리보기가 표시돼요.
1엑셀 양식 받기
각 행이 공문서 한 건이 돼요. 본문/붙임 칸에서 줄바꿈은 셀 안에서 Alt+Enter로 넣어주세요.
2작성한 엑셀 업로드
여기로 엑셀 파일을 끌어다 놓거나 클릭해서 선택하세요 (.xlsx)
3일괄 생성
모든 처리는 이 브라우저 안에서만 이뤄져요. 입력한 내용이 서버로 전송되지 않아요. · 실제 기관 명의로 발송하기 전에는 소속 기관의 공문서 규정 및 결재 절차를 확인해주세요.
