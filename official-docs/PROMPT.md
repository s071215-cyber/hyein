# 공문서 자동 생성기 재현용 프롬프트

이 문서는 `official-docs/`의 공문서 자동 생성기를 다른 프로젝트에서도 그대로
재현하고 싶을 때, 새 Claude Code 세션에 붙여넣어 쓰는 지침이에요.

---

```
공문서를 자동으로 만드는 도구를 만들어줘. 아래 사양대로 구현해줘.

## 목표
행정기관 표준 공문 서식에 맞춰 Word(.docx) 문서를 자동 생성하는 도구.
서버·API 키 없이 브라우저에서만 동작해야 함 (오프라인에서도 동작).

## 실행 방식 (2가지 모두 필요)
1. 브라우저 폼: 항목을 입력하면 오른쪽에 실제 공문서 모양으로 실시간 미리보기가 뜨고,
   버튼 클릭 시 .docx 파일이 다운로드됨.
2. 엑셀 대량 생성: "엑셀 양식 다운로드" 버튼으로 빈 양식(xlsx)을 받고,
   여러 행을 채운 엑셀을 업로드하면 행마다 문서 하나씩 만들어 ZIP으로 일괄 다운로드.

## 입력 항목 (행정기관 표준 공문 서식 기준)
기관명(발신 기관), 수신, 경유(선택), 제목, 본문(줄바꿈=문단 구분),
붙임(선택, 여러 줄), 발신명의, 문서번호, 시행일자,
우편번호, 주소, 전화번호, 팩스번호, 이메일, 공개구분(공개/부분공개/비공개)

## 문서 레이아웃 규칙
- 상단: 기관명 (중앙정렬, 굵게, 큰 글씨) + 아래 밑줄
- 수신 OOO (경유 OOO)
- 제목 OOO (굵게)
- 본문: 줄 단위로 문단 처리, 마지막 문단(붙임이 없으면 본문 마지막 줄,
  붙임이 있으면 붙임 마지막 줄) 끝에 "  끝." 자동으로 붙임
- 붙임: 첫 줄 앞에 "붙임  ", 이후 줄은 들여쓰기
- 발신명의: 중앙정렬, 굵게, 여백을 두고 크게 표시
- 하단: 구분선 + 작은 글씨로 "시행 문서번호(시행일자)", "우 우편번호  주소",
  "전화번호(...)  팩스번호(...)  /  이메일  /  공개구분: OOO"

## 기술 구현 방식 (중요)
- 순수 클라이언트 사이드 HTML/JS로 구현 (React 등 빌드 도구 불필요).
- Word 생성: npm의 `docx` 라이브러리 (Document/Paragraph/TextRun/BorderStyle API).
  브라우저 UMD 빌드(`build/index.umd.js`)를 사용하면 전역 변수 `window.docx`로 노출됨.
  `Packer.toBlob(doc)`으로 브라우저에서 바로 Blob 생성 가능.
- 엑셀 읽기/쓰기: SheetJS(`xlsx` 패키지)의 `dist/xlsx.full.min.js` (전역 `XLSX`).
- 여러 docx를 ZIP으로 묶기: `jszip` 패키지의 `dist/jszip.min.js` (전역 `JSZip`).
- 이 세 라이브러리는 CDN에 의존하지 말고 npm install 후 dist/build 파일을
  프로젝트의 vendor/ 폴더에 그대로 복사해서 <script src="vendor/...">로 로드할 것
  (오프라인 동작 보장, 회사/공공기관 네트워크의 CDN 차단 회피 목적).
- 폼 필드는 하나의 FIELDS 배열로 정의해서 폼 렌더링·엑셀 헤더·docx 생성 로직이
  모두 이 배열 하나를 공유하도록 만들 것 (중복 방지).

## 검증 방법
사전 설치된 Playwright/Chromium으로 실제 브라우저를 띄워
(1) 폼 입력 → 다운로드 버튼 클릭 → 받은 .docx를 압축 해제해 document.xml에
    입력 내용과 "끝." 표시가 들어갔는지 확인
(2) 엑셀 양식 다운로드 → 샘플 데이터로 업로드 → ZIP 생성 → 안의 여러 .docx가
    각각 올바른 내용을 담고 있는지 확인
콘솔에 JS 에러가 없는지도 함께 확인할 것.

## 주의사항
- 결과 페이지는 다운로드 기능이 핵심이므로 Claude Artifact로 미리보기 게시하지 말 것
  (Artifact 샌드박스는 스크립트 기반 다운로드를 막아서 핵심 기능이 동작하지 않음).
- 기안자/검토자/결재권자 결재란처럼 조직마다 다른 정식 결재 시스템 연동 부분은
  범위에서 제외하고, README에 "실제 발송 전 소속 기관 규정 확인 필요"라고 안내할 것.
```
