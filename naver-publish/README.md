# 네이버 블로그 반자동 발행 스크립트

`blog-master-writer` 스킬로 만든 원고를 네이버 블로그 글쓰기 화면에 자동으로 채워 넣고,
확인 후 발행까지 눌러주는 스크립트예요. **로그인은 항상 사람이 직접** 하고, 이후 세션만 재사용해요.

> ⚠️ 이 스크립트는 **내 컴퓨터(로컬)** 에서 실행해야 해요. 원격 세션에는 내 네이버 로그인이 없어서 실행할 수 없어요.

## 왜 이런 구조인가요?

원고를 그냥 텍스트로 밀어 넣으면 마크다운 기호(`**`, `#`, `>` 등)가 글자 그대로 남아요.
그래서 이 스크립트는 마크다운을 HTML로 변환한 뒤 **클립보드 붙여넣기**로 네이버 에디터에 넣어요.
사람이 워드/구글독스에서 복사해 붙여넣을 때 서식이 유지되는 것과 같은 원리예요.

## 1. 준비

```bash
cd naver-publish
npm install
```

시스템에 크롬(Chrome)이 설치되어 있어야 해요 (Mac/Windows 기본 설치 기준 자동 인식돼요).
크롬이 없다면 `publish.mjs`에서 `channel: 'chrome'` 줄을 지우고 아래를 한 번 실행하세요.

```bash
npx playwright install chromium
```

## 2. 원고 파일 만들기

`blog-master-writer` 스킬로 만든 글을 아래 형식의 `.md` 파일로 저장하세요 (예시: `sample-post.md`).

```
TITLE: 제목 텍스트
---

본문 마크다운 (## 소제목, **굵게**, > 인용구, 표, [링크](url) 등)
```

## 3. 실행

```bash
export NAVER_BLOG_ID=내블로그아이디   # 예: blog.naver.com/wantto012 라면 wantto012
node publish.mjs sample-post.md
```

- 처음 실행하면 브라우저 창이 뜨고, 로그인이 안 되어 있으면 직접 로그인(2단계 인증 포함)하라고 안내해요.
  로그인 세션은 `~/.naver-publish-profile` 폴더에 저장되어 다음부터는 로그인을 건너뛰어요.
- 기본은 **dry-run**이에요. 제목/본문을 채우고 스크린샷(`~/.naver-publish-profile/last-draft-preview.png`)만 남긴 뒤
  실제 발행은 하지 않아요. 브라우저 창에서 서식이 제대로 들어갔는지 직접 확인하세요.
- 확인 후 문제 없으면 `--publish` 옵션을 추가해서 실제로 발행하세요.

```bash
node publish.mjs sample-post.md --publish
```

## 주의할 점

- **로그인은 절대 자동화하지 마세요.** 아이디/비밀번호를 코드나 파일에 저장하지 않아요. 매번(최초 1회) 사람이 직접 로그인해요.
- 네이버는 짧은 시간에 반복적인 자동 발행을 이상 행동으로 감지해 계정을 잠그거나 캡차를 띄울 수 있어요.
  하루 1~2회 정도, 사람이 확인하는 간격을 두고 사용하는 걸 권장해요.
- 네이버 스마트에디터의 내부 구조(클래스명 등)가 바뀌면 선택자가 안 맞을 수 있어요.
  이 경우 콘솔 로그와 `last-draft-preview.png` 스크린샷을 확인해서 어느 단계에서 막혔는지 알려주면
  선택자를 다시 맞춰줄 수 있어요.
- 표/인용구/굵게 서식은 마크다운→HTML 변환 후 "붙여넣기"로 들어가기 때문에, 실제로 어떻게 반영되는지는
  dry-run 결과를 눈으로 반드시 확인해야 해요 (영상에서 보여준 문제가 바로 이 부분이었어요).
